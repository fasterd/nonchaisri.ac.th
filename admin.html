GitHub Personal Access Token

Token จะถูกจำไว้ถาวรในเบราว์เซอร์นี้ — ไม่ต้องใส่ใหม่ทุกครั้ง
ตรวจสอบว่า Token ยังใช้งานได้และมีสิทธิ์เขียน
ต้อง Login GitHub ด้วย account fasterd เท่านั้น
repo nonchaisri.ac.th อยู่ใต้ account fasterd — Token จาก account อื่นไม่มีสิทธิ์เขียน
ต้องใช้ Classic Token เท่านั้น (ไม่ใช่ Fine-grained)
1. Login GitHub ด้วย account fasterd แล้วไปที่ github.com/settings/tokens/new
2. Note: nonchaisri-admin | Expiration: No expiration
3. Scopes: ติ๊ก ✅ repo (ทั้งหมด)
4. กด Generate token → คัดลอก token (ขึ้นต้นด้วย ghp_)
5. วางในช่องด้านบน แล้วกด บันทึก
